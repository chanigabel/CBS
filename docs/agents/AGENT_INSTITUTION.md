# Agent Institution

## 1. Mission

Review and maintain Mosad-related behavior and institution-report validation.

## 2. Files To Inspect First

- `docs/standardization_rules/INSTITUTION_RULES.md`
- `src/excel_standardization/validation/institution_report_validator.py`
- `src/excel_standardization/services/sheet_name_resolver.py`
- `webapp/services/mosad_id_scanner.py`
- `webapp/services/derived_columns.py`
- `webapp/services/standardization_service.py`
- `webapp/services/workbook_service.py`
- `tests/test_institution_report_validator.py`

## 3. Rules Documents To Follow

- `docs/standardization_rules/INSTITUTION_RULES.md`
- `docs/standardization_rules/PIPELINE_RULES.md`
- `docs/standardization_rules/EXPORT_RULES.md`

## 4. What The Agent May Change

- Institution validation, Mosad metadata handling, UI/export injection, tests,
  and docs when requested.

## 5. What The Agent Must Not Change

- External-reference rules that are not implemented unless approved and supplied.
- Corrected fields generated by standardization engines.

## 6. Required Safety Constraints

- Validation may add `_validation_status` and `_validation_ok`.
- Validation should not rewrite source or corrected business fields.
- Unknown external dictionary checks must be documented as unavailable.

## 7. Required Tests Before/After Changes

- `pytest tests/test_institution_report_validator.py`
- `pytest tests/webapp/test_api_institution.py`
- `pytest tests/webapp/test_workbook_service.py`
- `pytest tests/webapp/test_export_service.py`

## 8. Expected Output Format

Report validation rule impact, UI/export impact, test coverage, and approval
items.

## 9. Review Checklist

- Known sheet canonicalization.
- MosadID injection and validation.
- SugMosad validation and scoping.
- Duplicate ID checks.
- Entry-day sheet-specific rule.

## 10. Regression Checklist

- Missing MosadID.
- Missing/invalid SugMosad.
- Duplicate IDs.
- Missing required names.
- Birth/entry date required checks.
